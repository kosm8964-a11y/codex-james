# 肥料订单生成项目

这是一个命令行版的肥料订单生成工具。运行后按提示输入订单号、肥料品种、数量、单价等信息，程序会自动计算金额并生成可直接发给客户的订单文本文件。

## 运行方式

```bash
python3 fertilizer_order_generator.py
```

## 生成结果

- 终端会显示订单预览。
- 程序会在 `orders/` 目录下生成一个 `.txt` 文件，文件名格式：`订单号_客户名称.txt`。

## 示例字段

- 订单号
- 客户名称
- 肥料品种
- 数量（吨）
- 单价（元/吨）
- 业务员
- 联系电话
- 送货地址
- 备注（可选）
